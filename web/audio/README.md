# Ses kaynakları

Bu klasördeki kayıtlar oyunla birlikte çevrimdışı kullanılır. Üçü de Creative
Commons Zero (CC0) kapsamında yayımlanmıştır; atıf zorunlu değildir. Kaynağın
izlenebilmesi için bilgiler burada tutulur.

- `countdown-heartbeat.mp3` — “Heartbeat”, JonasTisell / Andy Jack
  - https://freesound.org/people/JonasTisell/sounds/670465/
  - Gerçek kalp kaydı; 8,668 saniye.
- `countdown-clock.mp3` — “Clock Tick-Tock.wav”, Lynx_5969
  - https://freesound.org/people/Lynx_5969/sounds/418896/
  - Gerçek duvar saati kaydı; 2,001 saniyelik döngü.
- `calibration-rise.mp3` — “Reverse Cymbal Shiny”, loganzsound
  - https://freesound.org/people/loganzsound/sounds/774635/
  - Gerçek metal/perküsyon tabanlı yükseliş; 2,902 saniye.

İndirilen dosyalar Freesound'un tam uzunluktaki HQ MP3 önizlemeleridir.
